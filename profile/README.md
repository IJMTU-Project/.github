# IJMTU Project

# EVERYTHING YOU SEE HERE IS JUST A CONCEPT AT THE MOMENT AND SUBJECT TO CHANGE

## The IJMTU Project is:

* An independent Linux Distro
* from-scratch Package Manager

## The IJMTU Project is **NOT**:

* For-profit
* NOT Accepting donations (why would you want to)
* For beginners/people unfamiliar with Linux

## IJMTU Linux

IJMTU Linux (or I Just Made This Up Linux) is a from-scratch open-source Linux distribution based off of LFS (Linux From Scratch)

## Just Install

Just Install (`justinstall`) is our package manager. while it isn't the greatest package manager ever, it (might) get the job done 

## Distribution Rules

* If you fork a repo of ours, you are required to preserve original author attribution notices per our project licenses.
* It is highly recommended to keep forks FOSS (Free and Open-Source Software) to help the community understand what's different.
